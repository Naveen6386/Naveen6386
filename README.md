A Spring Boot backend system developed as part of the **JPMorgan Chase Advanced Software Engineering Virtual Experience Program**.

**Tech Stack:** Java • Spring Boot • Apache Kafka • Spring Data JPA • Hibernate • H2 • REST APIs

**Key Features:**

- Asynchronous transaction processing using Apache Kafka
- Financial transaction validation
- Sender and recipient balance management
- H2 database persistence
- JPA/Hibernate entity relationships
- External Incentive REST API integration
- REST API for retrieving user balances

🔗 **[View Midas Core](https://github.com/Naveen6386/forage-midas)**

### 🛒 myShopSphere — E-Commerce Backend

A production-grade **Java and Spring Boot e-commerce backend** designed to manage products, shopping carts, and customer orders through RESTful APIs.

**Tech Stack:** Java • Spring Boot • Spring Data JPA • Hibernate • MySQL • REST APIs • Maven

**Key Features:**

- RESTful CRUD APIs for product, cart, and order management
- Controller-Service-Repository layered architecture
- Spring Data JPA and Hibernate for database operations
- MySQL database integration
- Shopping cart and order management
- REST API testing using Postman
- Clean separation of business logic and persistence layers

🔗 [**View MyShopSphere**](https://github.com/Naveen6386/myShopSphere)
